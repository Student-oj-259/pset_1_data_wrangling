# pset_1_data_wrangling

## Data Wrangling — Problem Set 1

Generate synthetic person-level data and aggregate it into household-level statistics using Python, pandas, NumPy, Faker, and Polars.

## Contents

| File | Purpose |
| --- | --- |
| `fake_data_generation.py` | Generates synthetic people grouped into households. |
| `household_level.py` | Calculates household-level summary statistics. |
| `fake_users.csv` | Example person-level dataset containing 20 people. |
| `household_level_data.csv` | Example summary dataset containing eight households. |

## Setup

Install the required packages:

```bash
python -m pip install numpy pandas Faker polars
```

## How to use

Run commands from the repository directory because the scripts use relative file paths.

To aggregate the included person-level data:

```bash
python household_level.py
```

To generate a new dataset and then aggregate it:

```bash
python fake_data_generation.py
python household_level.py
```

These commands overwrite `fake_users.csv` and `household_level_data.csv`, respectively.

## Synthetic data

`create_fake_data(N, df_chisq=3)` returns a pandas DataFrame containing `N` people. The script currently calls it with `N=20` and `df_chisq=1`.

Household sizes are drawn from a chi-square distribution, rounded down, and increased by one. Each household is limited to seven people and the number of people still needed.

The person-level fields are:

| Column | Description |
| --- | --- |
| `household_id` | Unique household identifier. |
| `person` | Person number within the household, starting at 1. |
| `name` | Synthetic name generated by Faker. |
| `age` | Random integer from 10 to 100. |
| `income` | Random integer from 10,000 to 150,000; no currency is specified. |
| `female` | Random binary indicator: 0 or 1. |

The generated CSV also includes the pandas row index.

## Household summaries

`household_level.py` groups people by `household_id` and produces:

- `household_size`: number of people.
- `mean_age`, `max_age`, `min_age`: age summaries.
- `mean_income`, `max_income`, `min_income`: income summaries.
- `no_females`: sum of the `female` indicator.
- `female_main_earner`: `female` indicator of the person selected after sorting by income and taking the last row.
- `no_children`: number of people aged under 18.
